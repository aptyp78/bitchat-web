# BitChat Web

Веб-версия децентрализованного P2P мессенджера BitChat с поддержкой передачи файлов любого формата.

## 🔗 Особенности

- **Полностью P2P** — после первоначального обнаружения все сообщения идут напрямую между браузерами через WebRTC
- **Mesh-маршрутизация** — сообщения могут передаваться через другие узлы (до 7 хопов)
- **Передача файлов** — отправка файлов любого размера и формата с чанкированием
- **End-to-end шифрование** — приватные сообщения шифруются с использованием NaCl (Curve25519 + XSalsa20-Poly1305)
- **IRC-стиль команды** — /nick, /msg, /who, /slap и другие
- **Тёмная тема** — стильный интерфейс в crypto-mesh стиле

## 🚀 Запуск

### 1. Установка зависимостей

```bash
cd bitchat-web
npm install
```

### 2. Запуск (одной командой)

```bash
npm run dev
```

Это запустит:
- Signaling сервер на порту 3001
- Веб-клиент на порту 5173

### 3. Открыть в браузере

Автоматически откроется http://localhost:5173

## ⌨️ IRC-команды

| Команда | Описание |
|---------|----------|
| `/nick <имя>` | Сменить никнейм |
| `/who` | Показать список подключенных пиров |
| `/msg <ник> <сообщение>` | Отправить приватное сообщение |
| `/slap <ник>` | Шлёпнуть форелью (классика IRC) |
| `/me <действие>` | Действие от третьего лица |
| `/fingerprint` | Показать свой криптографический fingerprint |
| `/clear` | Очистить чат |
| `/help` | Показать справку |

## 🔐 Безопасность

- **Приватные сообщения** шифруются с помощью NaCl box (Curve25519 + XSalsa20-Poly1305)
- **Каждый пир** имеет уникальную пару ключей, генерируемую при первом запуске
- **Fingerprint** — SHA-256 хеш публичного ключа для верификации

## 📡 Архитектура

```
                    ┌─────────────────┐
                    │ Signaling Server │
                    │   (Socket.IO)   │
                    └────────┬────────┘
                             │
         ┌───────────────────┼───────────────────┐
         │                   │                   │
    ┌────┴────┐        ┌────┴────┐        ┌────┴────┐
    │ Browser │◄──────►│ Browser │◄──────►│ Browser │
    │  Peer A │ WebRTC │  Peer B │ WebRTC │  Peer C │
    └─────────┘        └─────────┘        └─────────┘
         │                                      │
         └──────────────── WebRTC ──────────────┘
                     (через Peer B как relay)
```

- **Signaling Server** — только для первоначального обнаружения и обмена WebRTC offer/answer
- **После подключения** — все данные идут напрямую P2P через WebRTC Data Channels
- **Mesh-маршрутизация** — если прямое соединение невозможно, сообщения передаются через другие узлы

## 🛠️ Технологии

- **WebRTC** — P2P соединения между браузерами
- **Socket.IO** — signaling для WebRTC
- **TweetNaCl** — криптография
- **Vite** — сборка и dev-сервер
